# spectre
An asynchronous multi-platform OSINT reconnaissance and digital footprint extraction engine built in Python.

## Usage

```bash
python /home/runner/work/spectre/spectre/main.py <username>
python /home/runner/work/spectre/spectre/main.py <username> --concurrency 8 --output report.json
```

## Dependencies

- aiohttp
- beautifulsoup4
